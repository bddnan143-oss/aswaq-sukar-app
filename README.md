# أسواق قلعة سكر | السوق الرقمي الموحد (Aswaq Qalat Sukkar)

منصة وسوق رقمي وتجاري متكامل لأهالي وأصحاب المتاجر والمشاريع في مدينة قلعة سكر.

## المميزات الرئيسية:
- **دليل المتاجر والأسواق**: تصفح الأقسام (غذائية، خضار وفواكه، لحوم، إلكترونيات، مطاعم، ملابس، مواد بناء، وغيرها).
- **كاشير المبيعات السريعة (POS)**: تسجيل المبيعات النقدية المباشرة وطباعة الفواتير ومشاركتها عبر واتساب وتحديث المخزون آلياً.
- **دفتر وسجل الديون الإلكتروني**: تتبع سحبيات الزبائن، دفعات التسديد، التنبيهات الدورية، وتوليد كشوفات الحساب بصيغة PDF.
- **إدارة المتجر والمخزون**: إضافة وتعديل وحذف المنتجات والأسعار والعروض وتحديد نسبة الخصم.
- **نظام الحفظ التلقائي**: تخزين البيانات في قاعدة البيانات ومزامنتها محلياً في المتصفح (`localStorage`).
- **تطبيق ويب تقدمي (PWA)**: يدعم التثبيت المباشر على الهاتف بنقرة واحدة والعمل دون إنترنت (Offline).
- **لوحة تحكم المشرف العام (Super Admin)**: إدارة الاشتراكات، رموز التفعيل، والمتاجر والمستخدمين.

---

## متطلبات التشغيل (Prerequisites):
- **Node.js** (الإصدار 18 أو أحدث)
- **npm** أو **yarn** أو **pnpm** أو **bun**

---

## خطوات التشغيل المحلي (Local Setup):

1. **تثبيت الحزم والمكتبات:**
   ```bash
   npm install
   ```

2. **بدء تشغيل بيئة التطوير (Development Server):**
   ```bash
   npm run dev
   ```
   افتح المتصفح على: `http://localhost:3000`

3. **بناء النسخة الإنتاجية (Production Build):**
   ```bash
   npm run build
   npm start
   ```

---

## بنية المشروع (Project Structure):
- `/src`: الواجهات ومكونات React مع TypeScript و Tailwind CSS.
- `/server`: خادم Node.js / Express وقاعدة البيانات المحلية المعزولة.
- `/public`: ملف بيان التطبيق `manifest.json`، أيقونات PWA، وكود `sw.js`.
